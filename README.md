# Wither Storm Add-on para Minecraft Bedrock

## Descripción
Add-on basado en la serie de Minecraft Story Mode que implementa el Wither Storm con:
- Modelo 3D detallado
- Texturas de alta calidad
- Sistema de 3 fases de combate
- Animaciones suaves
- Bloques corruptos
- Sistema de proyectiles
- Pelea final con bomba TNT

## Instalación
1. Descargar el archivo `.mcaddon`
2. Abrirlo con Minecraft Bedrock Edition
3. Activar en la configuración del mundo

## Características Principales
- **Wither Storm**: Jefe de 3 fases
- **Bloques Corruptos**: Bloques oscuros especiales
- **Sistema de Combate**: Múltiples patrones de ataque
- **Animaciones**: Movimientos fluidos y realistas
- **Recompensas**: Nether Stars y Diamonds
